# 공개 API 가 없는 매체 연결 — 리포트 CSV 업로드 (네이버 GFA · 모비온 · 그 외)

광고주용 무료 API 가 없는 매체는 **매체 관리자에서 일별 리포트를 내려받아 저장소 폴더에 올리면** 광고 탭에 다른 채널과 같은 형식으로 들어온다.

| 매체 | 폴더 | 리포트 내려받는 곳 |
|---|---|---|
| 네이버 GFA | `data/manual/gfa/` | GFA 관리자 → 보고서 → 기간 선택 → 분할: **일별** → 다운로드 |
| 모비온 | `data/manual/mobon/` | 광고관리 → 리포트 → **일별** → 엑셀 다운로드 → CSV 로 저장 |
| 네이버 브랜드검색 | `data/manual/brand_search/` | 브랜드검색 관리자 → 보고서 → 일별 |
| 새 매체 | `data/manual/<영문소문자>/` | 폴더만 만들면 자동 인식 (라벨은 `clients/manual_csv.py` `LABELS`) |

## 파일 규칙
- 확장자 `.csv`, 파일명 자유 (예: `2026-11.csv`). 한 폴더에 여러 파일 가능, 같은 날짜는 합산.
- 첫 줄 헤더에 아래 열이 있으면 자동 인식 (한글/영문, 순서 무관, 다른 열은 무시):
  `날짜` · `광고비`(비용) · `노출` · `클릭` · `전환` · `전환매출`(매출)
- 날짜 형식 `2026-11-01` / `2026.11.01` / `20261101` 모두 가능. 숫자의 쉼표·"원" 허용.
- 엑셀에서 "CSV(쉼표로 분리)" 로 저장하면 된다 (CP949 인코딩 자동 판별).
- 캠페인별 행이 있어도 그대로 넣으면 날짜별로 합산된다.

## 올리는 방법 (GitHub 웹, 1분)
1. `https://github.com/<owner>/<repo>/upload/main/data/manual/gfa` 열기 (폴더명만 바꿔서)
2. CSV 파일을 끌어다 놓기 → **Commit changes**
3. 다음 07:00 수집부터 반영. 바로 보려면 Actions → `ops daily collect` → Run workflow (`days` 는 올린 기간 길이)

## 주의
- 매체 리포트의 "전환"은 매체 자체 어트리뷰션(뷰스루 포함 등)이라 GA4·카페24 전환과 정의가 다르다. 채널표에는 매체 기준으로, GA4 전환 열에는 GA4 기준으로 나란히 보여준다.
- CSV 를 올리지 않은 기간은 그 채널 광고비가 빠져 **ROAS 가 과대**해 보인다. 월 1회라도 꾸준히 올릴 것.
- 크리테오는 API(`CRITEO_CLIENT_ID/SECRET`)가 있으므로 CSV 대신 API 연결 권장.
