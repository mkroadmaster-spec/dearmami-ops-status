# 무료 스택 확인표 — 모든 채널·도구 무료 티어로 운영

| 구분 | 도구 | 비용 | 무료 한도 / 조건 | 한도에 걸릴 때 |
|---|---|---|---|---|
| 코드·자동 수집 | GitHub Actions | 무료 | Public 저장소는 무제한. (Private 는 월 2,000분) | 현재 Public → 해당 없음 |
| 대시보드 웹 주소 | GitHub Pages | 무료 | 월 100GB 전송, 사이트 1GB | 대시보드 1.8MB → 월 5만 회 열람 가능 |
| 데이터 저장 | Neon Postgres | 무료 | 0.5GB, 프로젝트 1개, 카드 불필요 | 일 100KB 수준 → 10년치 이상 |
| 매출·주문·접속통계 | 카페24 Admin/통계 API | 무료 | 쇼핑몰 기본 포함, 앱 생성 무료 | 호출 제한(초당) 있으나 일 1회 수집이라 무관 |
| 방문자·전환·퍼널 | GA4 Data API | 무료 | 일 25,000 토큰(일반 속성) | 일 수십 호출 → 무관 |
| 메타 광고·소재 | Meta Marketing API | 무료 | 앱 생성·시스템 사용자 토큰 무료 | 호출 제한 있으나 일 수십 호출 → 무관 |
| 네이버 검색광고·키워드 | 네이버 검색광고 API | 무료 | 도구 → API 사용 관리에서 라이선스 발급 | 키워드 수백 개 단위 청크 호출로 처리 |
| 구글 광고 | Google Ads API | 무료 | 개발자 토큰 **기본 액세스 승인 필요**(수일), 승인 전엔 테스트 계정만 | 승인까지 다른 채널 먼저 운영 |
| 경쟁사 트렌드 | 네이버 데이터랩 API | 무료 | 일 1,000회 | 일 1회 → 무관 |
| 경쟁사 소재 | FB 광고라이브러리·구글 광고 투명성 **딥링크** | 무료 | 공식 무료 API 없음 → 링크로 확인 | 유료 크롤링(Apify 등)은 쓰지 않음 |
| 카카오 광고 | 카카오모먼트 API | 무료 | 비즈니스 채널 + 앱 등록 | 토큰 단기 만료 → 재발급 안내 |
| 알림 | 텔레그램 봇 / Slack Webhook | 무료 | 제한 없음(봇 초당 30건) | 무관 |
| 리포트 문서 | python-docx (Word 생성) | 무료 | 오픈소스 | — |
| 차트 | Chart.js | 무료 | 오픈소스(MIT), 번들 포함 | — |
| 실시간 서버(선택) | Render Web Service | 무료 | 월 750시간, 15분 무접속 시 슬립 | Pages 정적 배포만으로도 충분 → 선택 사항 |

**쓰지 않는 것(유료)**: Render Starter($7), 크롤링 서비스(Apify 등), 유료 BI 툴, 클로드 API(SNS 자동운영 C 덩어리에서만 필요 — 이 대시보드 범위 밖).

**원칙**: 자격증명이 없는 채널은 자동 스킵되므로, 무료 발급이 늦어지는 채널(구글 광고)은 건너뛰고 나머지를 먼저 운영한다.
