    채널 연결 순서

    쉬운 채널부터 하나씩. 키가 없는 채널은 자동 스킵되며, 한 채널만 채워도 그 채널만 수집됩니다.
    • config/secrets.env 에 해당 채널 값 입력 (cp config/secrets.env.example config/secrets.env)
    • python scripts/smoke_live.py --check 로 인증 확인 → python scripts/run_all.py --mode live --days 14
    • 이 화면 새로고침 → 아래 카드가 녹색이면 연결 완료. 순서·상세는 docs/SETUP-GUIDE.md
