# 탭 6·7 · 주간 리포트 / 월간 리포트 (`#weekly`, `#monthly`)

보고용 리포트를 자동으로 만든다. 두 탭은 **같은 틀**이고 기간만 다르다.

- 주간: 지난주(월~일) vs 그 전주
- 월간: 지난달 vs 그 전달

전체 배치: `screens/weekly-00-full.png` · 화면 코드: `loadReport()` / `bindRep()` / `downloadReport()` (`#repW`, `#repM`)
API: `/api/report/weekly?week=YYYY-MM-DD`, `/api/report/monthly?month=YYYY-MM` (+ 서버 실행 시 `.docx`)
코드: `cafe24_ops/etl/period_report.py` — 기간과 무관한 공통 함수 `period_report_data()` 를 `weekly_report()`·`monthly_report()` 가 부른다.

## 이 화면의 세 가지 원칙

1. **모든 표가 이전 기간과 이번 기간을 나란히 보여준다.** 열 구성은 `구분 | 이전 | 이번 | 증감`. 열이 많은 표(매체·네이버 키워드)는 값 아래 작은 글씨로 `전주 ₩x · ▲3%`.
2. **섹션마다 코멘트 칸이 있다.** 숫자를 근거로 자동 작성한 초안(`comments.<섹션>`)이 들어 있고, 사용자가 직접 고쳐 쓴다.
   - 고친 내용은 **그 브라우저의 localStorage** 에 저장된다(키: `rep:<client_id>:<weekly|monthly>:<기간>:<섹션>`). 다른 PC·브라우저에서는 보이지 않는다 — 사용자에게 이 점을 알려준다.
   - 칸 옆 태그가 `자동 초안` ↔ `직접 수정함` 으로 바뀐다. "초안으로 되돌리기"는 저장한 내용을 지운다.
3. **다운로드는 브라우저에서 만든다**(서버 불필요, GitHub Pages 에서도 동작). 화면의 표·그래프·코멘트 그대로 들어간다.
   - **Word**: HTML 기반 `.doc` (그래프는 그림으로 변환)
   - **Excel**: 표만 모은 `.xls`
   - **PDF**: 인쇄 창을 띄운다 → 대상에서 'PDF로 저장'. `@media print` 가 헤더·탭·브리핑을 숨긴다.
   - 파일 이름은 영문·숫자만 쓴다(`<client_id>_weekly-report_<기간>.doc`). 한글 이름은 일부 환경에서 확장자 없는 `download` 로 저장됐다.

## 알아둘 동작

- **섹션 번호는 실제로 그려지는 섹션만 순서대로 매긴다.** 데이터가 없는 섹션(GA4 미연결 등)은 건너뛰고 번호를 당긴다. 위 번호는 전부 있을 때 기준이다.
- **`missing_dates` 를 먼저 본다.** 그 기간 중 수집이 빠진 날짜 목록이다. 빠진 날이 있으면 합계가 작게 나온 것이므로, 숫자를 해석하기 전에 그 날짜를 재수집한다. 화면 머리말에도 경고가 뜬다.
- **완결된 기간만 쓴다.** `latest_complete_week()` 는 데이터가 있는 가장 최근의 완결 주(월~일)로 물러난다.
- **정적 페이지에는 최근 12주·12개월이 들어 있다**(`export_static.py` 의 `REPORT_WEEKS`, `REPORT_MONTHS` → `SNAP.reports_weekly`, `SNAP.reports_monthly`). 그 범위 안에서 이전/다음이 동작하고, 범위 밖은 버튼이 꺼진다.
- 문구의 "전주/전월"은 `prev_word` 한 변수로만 바꾼다.
- **섹션을 추가할 때**: `period_report_data()` 에 값(이전 기간 포함)과 `comments["<키>"]` 초안을 넣고, `loadReport()` 에 `sec(제목, 표 + cmt('<키>', r.comments.<키>))` 한 줄을 추가한다. 기존 키는 Word 생성(`report_docx.py`)이 쓰므로 이름을 바꾸지 말고 새 키를 더한다.
- **자동 생성**: `.github/workflows/cafe24-weekly-report.yml` 이 매주 월요일 08:25 KST 에 지난주 8일을 다시 수집하고 `.docx` 를 만들어 텔레그램으로 보낸다(설정 시). 수동은 `python scripts/weekly_report.py [--monthly]`.
  - 이 워크플로의 `env` 는 `daily-collect.yml` 과 **같아야 한다.** 채널 키가 빠진 채 수집이 돌면 그 채널이 안 들어온다(`operations.md` 의 사고 사례).
