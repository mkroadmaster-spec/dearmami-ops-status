# 공통 화면 (모든 탭 위쪽)

캡처: `screens/00-common-header-briefing-range.png` · 다크 모드 `screens/extra-dark-mode.png` · 모바일 `screens/extra-mobile.png`, `screens/extra-mobile-ads.png`

화면 전체는 `dashboard/index.html` **파일 하나**다(HTML + CSS + JS, 빌드 없음). 차트는 Chart.js(`dashboard/vendor/chart.umd.js` 동봉 — CDN 이 막힌 환경에서도 열리게).

## 1. 헤더

- **보여주는 것**: 브랜드명 + "운영 대시보드", 데이터 배지(`데모 데이터` 주황 / `LIVE` 녹색), 조회일, 마지막 수집 시각, 사이트 주소
- **출처**: `/api/config`(brand·site_url — `config/sources.yaml`), `/api/dates`(DB 의 최소·최대 날짜), `app_kv` 의 `data_mode`·`last_run_at`
- **조회일**: 기본값은 DB 에 데이터가 있는 마지막 날. 조회일을 바꾸면 브리핑과 기간(최근 N일의 끝)이 그 날 기준으로 바뀐다. 정적 페이지(GitHub Pages)에서는 고정이다.
- **주의**: 배지가 `데모 데이터`인데 실데이터를 기대했다면 `run_all.py --reset --mode live` 를 한 번도 안 돌린 것이다.

## 2. 탭

8개 탭. 주소 뒤 해시로 바로 열 수 있다: `#ops` `#ads` `#history` `#ga4` `#comp` `#weekly` `#monthly` `#channels`.
탭을 누르면 `section#tab-<이름>` 만 보이고 나머지는 `hidden`.

## 3. 오늘의 브리핑

- **보여주는 것**: 조회일 하루의 요약.
  - 이모지 요약 줄: 💰 매출·주문·객단가(7일 평균 대비) · 👀 방문자·전환율 · 📱 모바일/PC 비중 · 👥 신규/재구매 · 🏷 카테고리 상위 2 · 🏆 베스트 상품 3 · 📣 광고비·ROAS·매출대비 광고비 · ⛔ 품절 상품 수
  - 굵은 한 문장 요약
  - 4개 상자: **핵심지표**(전일·전주·전년 대비) / **7일 평균 대비 급등락**(±30% 이상만) / **이상치·신규 등장**(담기 0건 상품, 새로 등장한 검색어, 수집 실패 채널) / **광고 지표**(당일·전일·전주)
  - 오른쪽 위 "분석 접기" 버튼으로 상자를 접는다. 머리말 태그는 `특이사항 없음` 또는 `확인 필요 항목 있음`
- **출처**: `/api/digest?date=` → `cafe24_ops/alerts.py: digest()`
- **계산**: 7일 평균은 조회일 직전 7일. 급등락 기준 ±30%, ROAS 경고 기준 200% 미만.
- **같은 내용이 알림으로도 간다**: `scripts/notify.py` 가 Slack/텔레그램으로 전송(키가 있을 때만).

## 4. 기간 선택

- **기간 버튼**: 어제 · 최근 7일 · 최근 14일 · 최근 30일 · 직접 선택
- **비교 버튼**: 직전 기간(같은 길이의 바로 앞) · 전주 동기간(-7일) · 전월 동기간(-1개월) · 전년 동기간(-1년)
- 아래 줄에 선택기간·비교기간의 실제 날짜가 표시된다.
- **동작**: `computeRange()` 가 `RANGE = {from, to, cf, ct}` 를 만들고, 모든 데이터 API 에 `from=&to=&cmp_from=&cmp_to=` 를 붙인다(`q()`).
- **정적 페이지 제한**: GitHub Pages 판은 서버가 없어서 미리 만든 조합만 동작한다 — 기간 4종(1·7·14·30일) × 비교 4종. "직접 선택"은 서버(FastAPI)로 띄웠을 때만 쓸 수 있다.

## 5. KPI 카드·증감 표기 규칙

- 카드: 위쪽 파란 선, 라벨 → 큰 숫자 → 증감(`▲ 3.2% 비교기간 대비`).
- **색 규칙**: 오르면 좋은 지표(매출·ROAS…)는 ▲ 녹색 / ▼ 빨강. 오르면 나쁜 지표(광고비·CPC·CPA·매출대비 광고비)는 반대로 칠한다(`dcls()`).
- ROAS 는 `3.58x` 처럼 배수로 표기한다(내부 값은 %: 358).
- 숫자가 칸보다 길면 글자 크기를 11px 까지 자동으로 줄인다(`fitText()`), 줄바꿈하지 않는다.

## 6. 정적 페이지와 비밀번호

- 배포판은 `scripts/export_static.py` 가 API 응답을 통째로 스냅샷(`SNAP`)해 HTML 에 넣은 것이다. 화면 코드는 `api()` 대신 `snapGet()` 으로 스냅샷에서 꺼낸다.
- `DASHBOARD_PASSWORD` 가 있으면 스냅샷을 PBKDF2-SHA256(20만 회) → AES-256-GCM 으로 암호화하고, 브라우저에서 비밀번호를 넣어야 풀린다(`#gate`).
- **화면에 새 API 를 추가하면 반드시 두 곳을 같이 고친다**: `export_static.py` 의 스냅샷 목록과 `index.html` 의 `snapGet()` 경로 표. 빠뜨리면 서버에서는 되는데 배포판에서 "snapshot 에 없는 경로" 오류가 난다.
- **정렬·필터는 화면에서 한다.** 스냅샷에는 기본 정렬 한 가지만 들어 있으므로, 버튼으로 바꾸는 정렬은 서버에 다시 묻지 말고 받은 배열을 화면에서 정렬한다(네이버 키워드 정렬이 이 때문에 안 먹은 적이 있다).

## 7. 디자인 규칙

- 색 토큰은 `:root` 의 CSS 변수(`--s1`~`--s7` 계열색, `--good`/`--bad`/`--warn`), 다크 모드는 `prefers-color-scheme` 로 자동.
- 계열색 순서 고정: 파랑 → 주황 → 초록 → 노랑 → 분홍 → 보라. 차트를 추가할 때 `SERIES()` 순서대로 쓴다.
- 막대 두께 ≤ 24px, 선 2px, 범례는 계열이 2개 이상일 때만.
- 모바일 폭(390px)에서 가로 스크롤이 생기지 않아야 한다. 표는 패널 안에서만 스크롤.
